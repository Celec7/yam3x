# 使用指南

按下面的路径开始使用和维护已复制到应用中的组件。

## 开始使用

1. 按[安装与首次使用](/zh/guide/installation)配置目标 Vue/Vite 项目并添加组件。
2. 在[组件目录](/zh/components/)中查看示例、API 和 Material 规范链接。
3. 根据应用需要修改复制后的组件源码。

## 后续维护

- [更新已复制的源码](/zh/guide/updating)：比较新旧版本并手动合并更改。

[设计指南](/zh/guide/design)说明如何应用 Material 3 Expressive 排版、间距、页面布局和 YAM3X 组件。
