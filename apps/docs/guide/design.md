# Design foundations

Material 3 Expressive covers color, typography, shape, motion, and component states. This project provides dynamic theming, foundational styles, gesture utilities, and Vue components. Combine them to meet your product's content and interaction needs. See the [Material 3 design system](https://m3.material.io/) for the source guidance.

| Goal                                                               | Start here                                  | Material guidance                                                                                                                                                                                                 |
| ------------------------------------------------------------------ | ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Build light and dark themes from a brand color and adjust contrast | [Color and theming](/guide/theme)           | [Color](https://m3.material.io/styles/color/overview)                                                                                                                                                             |
| Use Roboto type roles and establish a clear text hierarchy         | [Heading](/components/heading)              | [Typography](https://m3.material.io/styles/typography/overview), [type scale and tokens](https://m3.material.io/styles/typography/type-scale-tokens), and [fonts](https://m3.material.io/styles/typography/fonts) |
| Choose component sizes, shapes, and emphasis                       | [Component catalog](/components/)           | [Components](https://m3.material.io/components)                                                                                                                                                                   |
| Configure motion and respect reduced-motion preferences            | [Color and theming](/guide/theme)           | [Motion](https://m3.material.io/styles/motion/overview)                                                                                                                                                           |
| Add pointer interactions such as dragging and long-press           | [Gestures and interaction](/guide/gestures) | [Foundations](https://m3.material.io/foundations/)                                                                                                                                                                |

Component pages describe the implemented API, interaction examples, and constraints. The repository's `docs/specs/` directory records implementation targets and platform differences.

The shared type scale includes baseline and emphasized roles. Use baseline roles by default; emphasized roles are for selected hierarchy and state. Add `lang` to localized content so typography tokens and component line heights can follow script needs. The default height category is medium; set `data-md-language-height="small|medium|large|extra-large"` on a subtree to override it. Components with fixed heights may need additional vertical space for taller scripts.
