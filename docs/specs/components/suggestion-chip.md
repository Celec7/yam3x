# Suggestion chips: project design guide

## Scope

Suggestion chips present product-generated next steps or responses that help narrow a person's intent. They are one of Material's four chip variants. See the [Chips overview](https://m3.material.io/components/chips/overview).

## Design target

### Use and content

- Use a Suggestion chip for a product-generated response or next step based on the current context. See [Chips guidelines: Suggestion chips](https://m3.material.io/components/chips/guidelines).
- Use a noun or short contextual phrase; keep the label to 20 characters or fewer when possible. See [Chips guidelines: Suggestion chip labels](https://m3.material.io/components/chips/guidelines).
- Group related suggestions, such as suggested replies or search refinements. See [Chips guidelines: Suggestion chip groups](https://m3.material.io/components/chips/guidelines).
- `suggestion-chip.behavior.activate`: Activating a suggestion performs the proposed next step or response. See [Chips overview: Suggestion chips](https://m3.material.io/components/chips/overview).

### Appearance and accessibility

- Keep each suggestion understandable without relying on an icon. See [Chips accessibility: labeling](https://m3.material.io/components/chips/accessibility).
- Follow the shared chip geometry, contrast, state feedback, and keyboard guidance in the [Chips family guide](chips.md).
